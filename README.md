# 🕹️ Tenzies

**Live: https://tenzies-nu-sooty.vercel.app/**

***Tenzies web app, play the the tenzies game in which you play to make all the faces of the die with same number to win!***

## ⚒️ Tech Stack:
- HTML 5
- CSS 3
- JavaScript
- [React](https://reactjs.org/) - JS library
- Vite
- React Confetti

## ✨ Installation / Running
1. Clone / download the zip of the repo.
2. Open the extracted folder of the repo in VS Code.
3. In the VS Code terminal run `npm i && npm run dev`.
4. That's it! Now you can make improvements / changes to the app and merge them via pull request.
